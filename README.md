# 투자문의 진단 위저드 — 목업

투자일임사 홈페이지의 투자 문의 페이지. 투자를 잘 모르는 사람도 질문에 답하는 것만으로
자기에게 필요한 것이 무엇인지 알고 문의를 마칠 수 있게 하는 화면입니다.

지금은 **목업 단계**입니다. 화면은 전부 동작하지만 데이터는 서버 메모리에만 있습니다.

## 실행

```bash
npm run dev
```

http://localhost:3000

## 문서

| | |
|---|---|
| [docs/api-spec.md](docs/api-spec.md) | **API 명세 v1.** 프론트엔드와 백엔드 사이의 계약. 화면은 이 명세대로만 호출합니다 |
| [docs/mock-data.md](docs/mock-data.md) | 목업 문의 14건이 어떤 경우를 덮는지 |

PRD 조항은 두 문서 모두 `§n`으로 참조합니다.

## 화면

| 경로 | 화면 | PRD |
|---|---|---|
| `/` | 문의 시작 | 01 |
| `/inquiry` | 위저드 — 구분 · 질문 · 연락처 · 인증 · 결과 | 02~08 |
| `/privacy` | 개인정보처리방침 | 09 |
| `/admin/login` | 담당자 로그인 | 10 |
| `/admin/inquiries` | 문의 목록 | 11 |
| `/admin/inquiries/[id]` | 문의 상세 · 결과지 발송 | 12 |

## 구조

```
src/
  app/
    api/v1/[...path]/route.ts   목업 API 서버 — 실제 백엔드가 붙으면 통째로 지운다
    inquiry/                    고객 위저드
    admin/                      담당자 화면
  components/inquiry/           위저드 단계별 화면
  components/admin/             담당자 화면 공통 조각
  lib/
    api/types.ts                API 계약 타입 — 화면은 이것만 본다
    api/client.ts               API 클라이언트 — 화면은 fetch를 직접 부르지 않는다
    wizard/branching.ts         조건부 문항 분기 판정
    mock/                       목업 데이터 — 실제 백엔드가 붙으면 통째로 지운다
```

**화면 코드는 `src/lib/mock`을 절대 import하지 않습니다.** `src/lib/api`만 봅니다.
이 경계가 지켜져야 백엔드를 갈아끼울 때 화면을 고치지 않습니다.

## 실제 백엔드로 바꾸는 방법

1. 백엔드가 [docs/api-spec.md](docs/api-spec.md)를 구현합니다.
2. `.env.local`의 주소를 바꿉니다.
   ```
   NEXT_PUBLIC_API_BASE_URL=https://api.example.com/v1
   ```
3. `src/app/api/v1`과 `src/lib/mock`을 지웁니다.

화면 코드는 손대지 않습니다.

## 목업이라서 이런 점이 다릅니다

- **데이터가 저장되지 않습니다.** 개발 서버를 다시 켜면 초기 14건으로 돌아갑니다.
- **인증번호는 `482913` 고정**이고 응답에도 들어 있습니다. 실제 백엔드는 난수로 만들고
  응답에 넣지 않습니다 (api-spec.md §4.5).
- **담당자 로그인 없이도 담당자 화면이 열립니다.** 클라이언트가 `X-Mock-Actor` 헤더로
  담당자를 흉내냅니다. 로그인 비밀번호는 `advisory`입니다.
- **메일이 실제로 발송되지 않습니다.** 결과지 발송은 시각만 기록합니다.
- **결과지 PDF가 만들어지지 않습니다.** 미리보기로 서식만 확인할 수 있습니다.

## 아직 임시값인 것

`src/lib/mock/catalog.ts`에 `PLACEHOLDER` 주석이 붙어 있습니다.

| 값 | PRD | 현재 |
|---|---|---|
| 최소 가입금액 | §15-1 | 1억 원 |
| 금액 구간 경계 | §15-1 | 개인 3천만/1억/3억/10억 · 법인 5억/20억/100억 |
| 전략군 이름 5개 | §15-2 | `원금 지키기 중심` 등 |
| 상호·등록번호, 손실 경고 문구 | §15-6 | 화면에 `[PLACEHOLDER]`로 표시 |
| 개인정보 보유기간, 위탁 고지 | §15-5 | `/privacy`에 `[PLACEHOLDER]`로 표시 |

전략군 설명에는 숫자가 하나도 들어 있지 않습니다. 예상 수익률·자산 비중·최대 낙폭은
PRD §3 원칙 3에 따라 넣지 않았고, 문구를 손볼 때도 넣지 않아야 합니다.
